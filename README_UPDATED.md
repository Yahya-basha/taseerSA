# نظام تسعيّر - منصة SaaS لإدارة تسعير قطع غيار السيارات

## 📖 نظرة عامة

**تسعيّر** هو نظام متقدم لإدارة تسعير قطع غيار السيارات، مصمم للشركات والموزعين. يوفر النظام:

- 🏢 **Multi-Tenancy**: دعم شركات متعددة مع عزل كامل للبيانات
- 👥 **إدارة المستخدمين**: إدارة متقدمة للموظفين والأدوار
- 💰 **التسعير الذكي**: حساب الأسعار بناءً على هوامش الربح
- 📄 **عروض الأسعار**: توليد عروض احترافية بصيغة PDF مع الباركود
- 📊 **التقارير**: تحليلات وتقارير شاملة
- 🎨 **التخصيص**: دعم الألوان والشعارات المخصصة لكل شركة
- 🔐 **الأمان**: مصادقة آمنة وعزل بيانات كامل

---

## 🚀 البدء السريع

### المتطلبات
- **Backend**: Python 3.8+, MongoDB
- **Frontend**: Node.js 14+, npm/pnpm
- **إضافي**: python-barcode, pillow

### التثبيت

#### 1. الواجهة الخلفية (Backend)

```bash
cd backend

# تثبيت المتطلبات
pip install -r requirements.txt

# تثبيت مكتبات إضافية
pip install python-barcode pillow

# إعداد متغيرات البيئة
export MONGO_URL="mongodb://localhost:27017"
export DB_NAME="taseer_db"
export SECRET_KEY="your-secret-key-here"

# تشغيل الخادم
uvicorn server:app --reload
```

الخادم سيعمل على: `http://localhost:8000`

#### 2. الواجهة الأمامية (Frontend)

```bash
cd frontend

# تثبيت المتطلبات
npm install
# أو
pnpm install

# إعداد متغيرات البيئة
# أنشئ ملف .env
echo "REACT_APP_BACKEND_URL=http://localhost:8000" > .env

# تشغيل التطبيق
npm start
# أو
pnpm start
```

التطبيق سيعمل على: `http://localhost:3000`

## 🔐 الأمان

### المصادقة
- JWT Token-based authentication
- كلمات مرور مشفرة (bcrypt)
- Token expiration

### عزل البيانات
- كل مستخدم يرى فقط بيانات شركته
- التحقق من `company_id` في كل استعلام
- منع الوصول المباشر للبيانات الأخرى

### الصلاحيات
- Role-based access control (RBAC)
- ثلاث أدوار: Super Admin, Admin, Employee
- صلاحيات مختلفة لكل دور

## 🐛 استكشاف الأخطاء

### المشكلة: لا يمكن الاتصال بـ MongoDB
**الحل**: تأكد من تشغيل MongoDB وأن `MONGO_URL` صحيح

### المشكلة: خطأ في توليد الباركود
**الحل**: تأكد من تثبيت `python-barcode` و `pillow`

### المشكلة: الواجهة الأمامية لا تتصل بالخادم
**الحل**: تأكد من أن `REACT_APP_BACKEND_URL` صحيح
