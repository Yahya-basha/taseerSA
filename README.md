## 📖 نظرة عامة

**تسعيّر** هو نظام متقدم وموثوق لإدارة تسعير قطع غيار السيارات. مصمم خصيصاً للشركات والموزعين، يوفر النظام:

- 🏢 **Multi-Tenancy**: دعم شركات متعددة مع عزل كامل للبيانات
- 👥 **إدارة متقدمة للموظفين**: تعديل وحذف وتفعيل/تعطيل الموظفين
- 💰 **التسعير الذكي**: حساب الأسعار بناءً على هوامش الربح المخصصة
- 📄 **عروض أسعار احترافية**: توليد PDF مع الباركود والألوان المخصصة
- 📊 **تقارير شاملة**: تحليلات وإحصائيات مفصلة
- 🎨 **تخصيص كامل**: دعم الألوان والشعارات المخصصة لكل شركة
- 🔐 **أمان عالي**: مصادقة آمنة وعزل بيانات كامل

---

## 🚀 البدء السريع

### المتطلبات
- **Node.js** 14+ و **npm/pnpm**
- **Python** 3.8+
- **MongoDB** (محلي أو MongoDB Atlas)

### التثبيت المحلي

#### 1. الواجهة الخلفية (Backend)

```bash
cd backend

# تثبيت المتطلبات
pip install -r requirements.txt

# إعداد متغيرات البيئة
cp .env.example .env
# ثم عدّل .env بقيمك الخاصة

# تشغيل الخادم
uvicorn server:app --reload
```

الخادم سيعمل على: `http://localhost:8000`

#### 2. الواجهة الأمامية (Frontend)

```bash
cd frontend

# تثبيت المتطلبات
pnpm install
# أو
npm install

# إعداد متغيرات البيئة
cp .env.example .env

# تشغيل التطبيق
pnpm start
# أو
npm start
```

التطبيق سيعمل على: `http://localhost:3000`

## 🔐 الأمان

### المصادقة
- JWT Token-based authentication
- كلمات مرور مشفرة (bcrypt)
- Token expiration

### عزل البيانات
- كل مستخدم يرى فقط بيانات شركته
- التحقق من `company_id` في كل استعلام
- منع الوصول المباشر للبيانات الأخرى

### الصلاحيات
- Role-based access control (RBAC)
- ثلاث أدوار: Super Admin, Admin, Employee
- صلاحيات مختلفة لكل دور

## 🐛 استكشاف الأخطاء

### المشكلة: لا يمكن الاتصال بـ MongoDB
**الحل**: تأكد من تشغيل MongoDB وأن `MONGO_URL` صحيح

### المشكلة: خطأ في توليد الباركود
**الحل**: تأكد من تثبيت `python-barcode` و `pillow`
```bash
pip install python-barcode pillow
```

### المشكلة: الواجهة الأمامية لا تتصل بالخادم
**الحل**: تأكد من أن `REACT_APP_BACKEND_URL` صحيح
